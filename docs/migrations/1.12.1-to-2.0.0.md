# Migrate from ModernFormsNext 1.12.1 to 2.0.0

## Bitmap interpolation with SkiaSharp 4

SkiaSharp 4 removes `SKFilterQuality` from its public compile-time API.
`ModernFormsNext.WindowKit.Skia.SkiaSharpExtensions.ToSKFilterQuality()`
was replaced by `ToSKSamplingOptions()`, which returns `SKSamplingOptions`.

This is a source and binary breaking change for callers of the removed method.
Update the source and rebuild each application, library or plugin that uses it.
A previously compiled call still refers to the removed signature and can fail
with `MissingMethodException` when executed with the new WindowKit assembly.

| `BitmapInterpolationMode` | Previous `SKFilterQuality` | New `SKSamplingOptions` |
| --- | --- | --- |
| `None` | `None` | Nearest filter, no mipmaps |
| `Unspecified` | `Low` | Linear filter, no mipmaps |
| `LowQuality` | `Low` | Linear filter, no mipmaps |
| `MediumQuality` | `Medium` | Linear filter and linear mipmap interpolation |
| `HighQuality` | `High` | Mitchell cubic resampling |

For the same `canvas`, `image`, and `destination`, the old call set the sampling
quality on the paint.

```csharp
using ModernFormsNext.WindowKit.Media.Imaging;
using ModernFormsNext.WindowKit.Skia;
using SkiaSharp;

var mode = BitmapInterpolationMode.HighQuality;
using var paint = new SKPaint { FilterQuality = mode.ToSKFilterQuality() };
canvas.DrawImage(image, destination, paint);
```

With SkiaSharp 4, pass the options directly to the drawing overload.

```csharp
using ModernFormsNext.WindowKit.Media.Imaging;
using ModernFormsNext.WindowKit.Skia;

var mode = BitmapInterpolationMode.HighQuality;
canvas.DrawImage(image, destination, mode.ToSKSamplingOptions());
```

If the original paint also sets opacity, a color filter or a blend mode, pass
that paint as the argument after the sampling options.

## First paint on Windows

Applications using the Windows software renderer can take longer to complete
their first paint after moving to the 4.x dependency stack. In the matched
migration trials, the extra cost appeared on first use of glyphs in Skia
and DirectWrite, including text drawn in the managed title bar. Keep the usual text and window
decorations when checking first-frame time on representative target machines.
[S02-c measurements and conditions](../development/2.0.0/MODERNFORMSNEXT-2.0.0-S02-C-REPORT.md#ukierunkowana-diagnostyka-windows).
