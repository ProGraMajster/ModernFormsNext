# ModernFormsNext 1.11.1 release notes

ModernFormsNext 1.11.1 is a compatible patch release focused on scrolling and layout correctness.

- Fixed [#130](https://github.com/ProGraMajster/ModernFormsNext/issues/130): scrollable derived
  layouts, including FlowLayoutPanel, now preserve and correctly reconcile their scroll position
  across hide/show, relayout and range changes.
- Kept scrollbar value, canonical scroll offset, DisplayRectangle/layout origin and child
  geometry synchronized.
- Fixed Anchor behavior when resizing shrinks the available scroll range.
- Added extensive regression coverage including a real Windows HWND scenario, FlowLayoutPanel,
  TableLayoutPanel, custom layouts, accessibility and wheel/thumb/track scrolling.

All eleven public NuGet packages and the matching Visual Studio extension use version `1.11.1`.
Library `AssemblyVersion` remains `1.11.0.0`; package/file versions advance to `1.11.1`/`1.11.1.0`.
The VSIX assembly/file version is `1.11.1.0`. No public API is removed or renamed.

Custom layout engines should position children relative to the translated `DisplayRectangle`
origin and must not subtract the scroll offset a second time. See the
[scroll layout contract](development/scroll-layout-regression.md) for details.

Windows remains the primary runtime. Android remains **Experimental**; existing platform and
Designer limitations are unchanged. This patch does not claim new device or screen-reader acceptance.
