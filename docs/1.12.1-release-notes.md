# ModernFormsNext 1.12.1 release notes

ModernFormsNext 1.12.1 is a compatible patch for the 1.12 series. It uses .NET 10 and SkiaSharp 3.119.2. Windows is the primary stable runtime, and Android remains **Experimental**. [1.12.0 release notes](1.12.0-release-notes.md) · [Changelog](../CHANGELOG.md)

## File and folder pickers

`FolderBrowserDialog`, `OpenFileDialog`, and `SaveFileDialog` now let the picker provider choose the starting location when `InitialDirectory` is null, empty, or whitespace-only. This fixes an exception before the picker opened when applications passed an empty folder field. An explicit `InitialLocation` takes precedence, including storage folders returned by the Android picker. [Issue #549](https://github.com/ProGraMajster/ModernFormsNext/issues/549)

Existing local directories are still suggested. Relative paths resolve against the working directory. A directory the framework cannot find supplies no hint. Malformed paths can still fail during path resolution.

## Upgrading

Update the ModernFormsNext packages used by your app to 1.12.1 and use the matching 1.12.1 template package or Designer VSIX when applicable. Existing 1.12.0 code can keep using the same public API and library assembly identity `1.12.0.0`. [Installation guide](installation.md)
