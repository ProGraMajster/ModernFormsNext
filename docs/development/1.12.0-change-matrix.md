# 1.12.0 change coverage matrix

This audit compares the last public tag, [v1.11.1](https://github.com/ProGraMajster/ModernFormsNext/releases/tag/v1.11.1)
(`dc55839b061485121a8e5dd8092ea2a79e4d7572`), with the feature baseline
[`caadff6`](https://github.com/ProGraMajster/ModernFormsNext/commit/caadff657d48458ec8c2b9221f0e8b5ee9dfe06d).
It covers the feature train before the documentation and version preparation.
The verification used the first-parent changes, constituent commits, final tree,
public contracts and tests, plus current GitHub milestone and Project #3
metadata. An issue link can identify a related objective without that PR
closing the issue. Rows without issue links are tracked by their PR.

The source comparison spans **188 commits**, **79 merged PRs** and **980 changed
paths**. This table maps each merge and its introduced commits to the relevant
[1.12.0 changelog](../../CHANGELOG.md). Data-only Designer behavior and
private executable-preview qualification appear under their respective scope.
The broader release preparation adds documentation, release metadata and the
build-time MessagePack patch after this feature baseline.
