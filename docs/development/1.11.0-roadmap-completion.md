## Issue #68 — safe custom-control metadata

### Initial audit, before implementation

the project's target is 1.11.0 but its Planned status, missing milestone and target
label need reconciliation. Existing #32/#42 infrastructure is retained.

| Acceptance criterion | Initial status | Evidence and implementation boundary |
|---|---|---|
| Source and binary discovery without execution | PARTIAL | Syntax-only `DesignerProjectUserControlDiscovery` handles public top-level source UserControls and inheritance. Referenced PE metadata is missing. |
| Properties, defaults, categories, safe conversions and events | MISSING for custom types | Existing `DesignMetadataReader` and Property Grid support trusted framework reflection. Custom types are skipped; no safe custom-member adapter exists. Reflection attributes, getters and constructors must remain confined to framework types. |
| Refresh after rebuild/reference changes | MISSING | Session and Toolbox retain one immutable startup list; preview cache only keys project path. Refresh must replace catalog/cache atomically without document/history mutations. |
| Safe placeholder/projection | PASS foundation | `DesignerEmbeddedPreviewCache` reads matching `.mfdesign` data, and renderer uses framework-only runtime types. Keep unknown/binary-only types as placeholders; never instantiate custom types. |
| Stale/incompatible/unsupported diagnostics | PARTIAL | Source read failures are mostly silent; binary resolution, missing/stale builds and unsupported members need actionable Output messages. |
| Nested/inherited controls and round-trip/runtime parity | PARTIAL | Existing UserControl tests cover document nesting, atomic selection, generated partial classes and data-only preview. Add metadata inheritance, reference refresh, custom property/event round trips and explicit compiled-fixture parity tests. |

Implementation will extend the existing discovery service using the repository's
existing Roslyn dependency to read symbols from source and PE bytes. Detached
internal descriptors adapt those symbols to the current Toolbox, Property Grid,
`DesignPropertyValue`, event bindings and code generator. No second document model,
assembly execution, MSBuild target execution, arbitrary converters or runtime custom
preview engine is introduced. Supported project/reference resolution must be explicit;
unsupported project evaluation and executable-only metadata receive diagnostics.
Tests will include constructor/getter/static initializer/attribute/converter traps,
rebuilt or removed references, inherited and nested UserControl documents, undo/redo,
serialization, reverse synchronization and compilation of generated event handlers.

### Implemented scope and acceptance

The existing discovery service now reads source and PE symbols without loading user
assemblies. Detached metadata feeds the existing Toolbox, Property Grid, document
values, event bindings, transactions and generator. Trusted framework base editors
remain available for custom subclasses. Explicit Refresh replaces metadata and
preview caches; missing types stay atomic placeholders even when their names contain
`Panel`. No application startup, constructor, getter, delegate, attribute or converter
code is executed during discovery. `ResolveControlType` is confined to the trusted
framework assembly. Package versions and runtime rendering code are unchanged.

| Criterion | Implemented result | Evidence boundary |
|---|---|---|
| Source/binary discovery | PASS supported contract | Roslyn symbols, literal HintPath, conventional ProjectReference outputs and restored package compile assets; no MSBuild target execution. |
| Custom/inherited properties and events | PASS supported contract | Encoded design/component metadata, safe primitive/enum defaults/conversion, inherited custom members and trusted framework base editors, typed void-event stubs. Unsupported CLR values/converters/signatures are read-only or rejected with diagnostics. |
| Refresh | PASS | Source/reference replacement, removed DLLs, preserved document/selection/history, refreshed grid/Toolbox and preview version. |
| Placeholders/safety | PASS | Throwing constructor/getter/static initializer/attribute/converter/delegate fixtures; assembly-load observer; unknown controls remain atomic after removal/reopen. |
| Failure diagnostics | PASS supported contract | Invalid/missing binaries, newer framework references, ambiguous types, stale conventional builds/assets, unsupported project evaluation and malformed assets. |
| Round trip and parity | PASS automated | Nested UserControl document containing a binary widget, generic-base member metadata, serializer/reverse parser, generated handler compilation and explicitly executed benign runtime fixture. Existing recursive preview tests are retained. |
