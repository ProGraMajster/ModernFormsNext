## Build tooling blocker

[CVE-2026-62900 / GHSA-23fw-v26w-5fgq](https://github.com/advisories/GHSA-23fw-v26w-5fgq)
lists Microsoft.Build.Tasks.Git 10.0.301 as affected and states that the 10.0.2xx
SDK feature band is no longer serviced. Both the explicit build dependency and
the SDK pin must use patched tooling. The already installed SDK 10.0.401 and
[SourceLink 10.0.401](https://www.nuget.org/packages/Microsoft.SourceLink.GitHub/10.0.401)
keep the .NET 10 target while aligning local and CI builds. This is a release
blocker fix, not a runtime API or framework version change. Acceptance requires
fresh restore/audit, builds, tests and packaging with no warning suppression.

## Findings and fixes during the audit

### Published pointer-event compatibility

The first raw ApiCompat run against the downloaded 1.10.0 release packages found
20 changed `RawPointerEventType` constants. Inserting `CaptureLost` after
`LeaveWindow` had shifted every subsequent value, which could misinterpret input
from an already compiled backend. The fix preserves the original 0–20 values
explicitly and assigns the additional event 21. No public member is removed.
The regression test failed 21/22 cases before the fix and passed 22/22 afterward.
This restores compatibility rather than requiring a breaking-change decision.

Raw attribute comparison also reports compiler-generated accessor/state-machine
metadata and nullable-context encoding changes. These are being reviewed separately
with effective Roslyn signature/nullability comparison; they are not silently
discarded or presented as an unfiltered ApiCompat pass.

### GitHub metadata reconciliation

The actual project Target 1.11.0 field, current closed states and merged PR history
confirmed #33, #42, #71, #83 and #98. Their milestone and target labels now agree;
#120's stale target 1.10 label is replaced by 1.11. The milestone description now
describes the actual frozen scope instead of future pages/navigation/AppShell.
#41/#68 remain closed, and #62/#63/#69 remain open/partial. No Future/1.12 target
was moved. The milestone contains eight closed and three open issues.

### Tooling validation before the compatibility fix

Commit `28751ce` passed clean Debug/Release solution builds with zero warnings and
errors, full tests (3565/3565 each, zero skipped), and a fresh transitive NuGet
vulnerability query with no reported vulnerable packages. The additional enum fix
requires rebuilt acceptance artifacts; these first results are not relabeled as
its validation.
