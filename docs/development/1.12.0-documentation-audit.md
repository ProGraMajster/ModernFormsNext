# 1.12.0 documentation audit and coverage

The baseline scope is the 167 Markdown files in the repository root
documentation, `docs/` and `docs-site/` at `caadff6`. The inventory included
relative links, normalized contents, navigation, current version references,
and coverage against public APIs. Compare the [change coverage
matrix](1.12.0-change-matrix.md) for commits and issues.

## Control and window coverage

The [catalog](../controls/README.md) is matched against the exported types
of the built framework assembly. It includes concrete public
`Control` descendants and `Control` itself, with Form and other concrete
`WindowBase` descendants counted separately. Abstract bases, item models,
Designer tooling controls and backend peers are outside the control count.
`NavigationHeader` is public and concrete, and its example uses the owner
to obtain it. The [component inventory](../controls/components.md) includes
standalone dialogs and other application-facing component types.

Four window types and four components also have individual guides. Run
`scripts/Test-ControlDocumentation.ps1` after building the Windows framework
target. The validator compiles the guide fragments, checks each listed
property name against the assembly, and verifies the two navigation
entries and coverage of public concrete controls and windows. Compile checks
validate C# syntax and member resolution. Platform matrices track live
behavior and device coverage.

## Updated and new documents

- All 77 type-specific pages, the control catalog, fundamentals and the
  components inventory are new. Guides link to the existing long-form
  RichTextBox, Markdown, ToolTip, collection, Designer and platform references.
- The detailed [changelog](../../CHANGELOG.md),
  [release notes](../1.12.0-release-notes.md) and new
  [migration guide](../migrations/1.11.1-to-1.12.0.md) distinguish source features,
  compatibility changes, platform evidence and qualification-only work.
- The README, installation, getting started, TestHost, template and extension
  documents align examples with the coordinated version. The published 1.11.1
  notes and historical samples retain their original version information.
- The [user index](../README.md), the offline home page, API reference home and
  DocFX TOC expose control pages and release/migration links. The development
  index records the separate scope, change and documentation audits.
- The Android backend and support matrix describe the new package, appearance
  provider, bounded Form host and service limits. The live limitations and
  platform features pages link to implemented Designer, virtualization and
  native hosting capabilities and distinguish the remaining gaps.
- XML summaries and remarks for selected controls supplement the practical guides
  with default, ownership, parameter and event information.
